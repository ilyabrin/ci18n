# Справочник API

Все публичные функции, сгруппированные по назначению. Заголовок подробно
описывает каждую рядом с её объявлением; эта страница служит картой.

Все функции, принимающие или возвращающие текст, работают в UTF-8. Функции,
пишущие в буфер, ведут себя как `snprintf()`: пишут не больше
`capacity - 1` байт, всегда завершают строку и возвращают длину, которую имел
бы весь результат.

Последний столбец называет макрос, который выключает функцию, если такой
есть; см. [Что можно выключить](embedded-and-size.md#что-можно-выключить).
AVR там значит, что функция возвращает перевод указателем, а на AVR он может
указывать во флеш, поэтому её вызов даёт ошибку компиляции; вместо неё есть
функции `_copy`. См. [Arduino и AVR](embedded-and-size.md#arduino-и-avr).

## Инициализация

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_init()` | Инициализирует каталог по умолчанию; до неё любой другой вызов не работает | |
| `ci18n_free()` | Освобождает всё, что он держит | |
| `ci18n_is_initialized()` | Был ли вызван `ci18n_init()` | |

## Загрузка

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_load_language(code, path)` | Загружает файл `key=value`, сливая с языком | `NO_FILES` |
| `ci18n_load_from_buffer(code, text, len)` | То же из памяти | |
| `ci18n_load_mo(code, path)` | Загружает файл `.mo` из gettext | `NO_MO`, `NO_FILES` |
| `ci18n_load_mo_from_buffer(code, data, len)` | То же из памяти | `NO_MO` |
| `ci18n_use_compiled(code, &compiled)` | Использует язык, собранный `tools/ci18n_compile`; ничего не копирует | `NO_COMPILED` |
| `CI18N_KEY(name)` | Ключ как строка; ошибка компиляции, если среди сгенерированных ключей его нет | |

## Выбор языка

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_set_current(code)` | Выбирает язык, в котором ищутся переводы | |
| `ci18n_set_fallback(code)` | Выбирает язык, который отвечает за то, чего нет в текущем | |
| `ci18n_get_current()` | Код текущего языка | |
| `ci18n_get_languages(out, cap)` | Загруженные языки; возвращает их число | |
| `ci18n_detect_locale(out, cap)` | Локаль системы, нормализованная: `ru-RU` | `NO_LOCALE` |
| `ci18n_set_current_best(locale)` | Текущий язык по лучшему совпадению, `ru-RU`, затем `ru`; `NULL` спрашивает систему | `NO_LOCALE` |

## Поиск

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_get(key)` | Перевод или `NULL` | AVR |
| `ci18n_get_or_key(key)` | Перевод или сам ключ | AVR |
| `ci18n_get_copy(key, out, cap)` | Копирует его в ваш буфер; безопасный вариант для потоков и вариант для AVR | |
| `ci18n_has(key)` | Есть ли ключ в текущем или запасном языке | |
| `ci18n_count(code)` | Число записей в языке | |
| `ci18n_foreach(code, fn, user_data)` | Вызывает `fn` для каждой записи | |

## Изменение

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_set(code, key, value)` | Добавляет или заменяет одну запись | |
| `ci18n_remove(code, key)` | Удаляет одну запись | |
| `ci18n_clear(code)` | Очищает язык, оставляя его загруженным | |
| `ci18n_remove_language(code)` | Выгружает язык и освобождает его слот | |

## Плюралы и порядковые формы

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_plural(key, n)` | Форма плюрала для `n` или `NULL` | AVR |
| `ci18n_plural_or_key(key, n)` | То же или ключ | AVR |
| `ci18n_plural_copy(key, n, out, cap)` | Копирует форму плюрала в ваш буфер | |
| `ci18n_plural_category(code, n)` | Категория CLDR для `n` | |
| `ci18n_plural_category_name(cat)` | `"one"`, `"few"` и так далее | |
| `ci18n_ordinal(key, n)` | Порядковая форма: 1st, 2nd, 3rd | `NO_ORDINALS`, AVR |
| `ci18n_ordinal_or_key(key, n)` | То же или ключ | `NO_ORDINALS`, AVR |
| `ci18n_ordinal_copy(key, n, out, cap)` | Копирует порядковую форму в ваш буфер | `NO_ORDINALS` |
| `ci18n_ordinal_category(code, n)` | Порядковая категория CLDR для `n` | `NO_ORDINALS` |

## Форматирование

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_format(out, cap, key, name, value, ..., NULL)` | Заполняет плейсхолдеры `{name}` | `NO_FORMAT` |
| `ci18n_format_plural(out, cap, key, n, ..., NULL)` | Форма плюрала с подстановкой; `{count}` это `n` | `NO_FORMAT` |
| `ci18n_format_ordinal(out, cap, key, n, ..., NULL)` | Порядковая форма с подстановкой | `NO_FORMAT`, `NO_ORDINALS` |
| `ci18n_set_formatter(name, fn, user_data)` | Регистрирует функцию вывода для `{value:name}` | `NO_FORMAT` |
| `ci18n_remove_formatter(name)` | Забывает её | `NO_FORMAT` |
| `ci18n_format_number(out, cap, code, number, digits)` | Число так, как его пишет язык | `NO_NUMBERS` |
| `ci18n_set_bidi_isolation(on)` | Оборачивает подставленные значения в FSI и PDI | `NO_FORMAT` |

## Направление текста

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_direction(code)` | `CI18N_DIR_LTR` или `CI18N_DIR_RTL` для любого кода | |
| `ci18n_current_direction()` | То же для текущего языка | |
| `ci18n_direction_name(dir)` | `"ltr"` или `"rtl"`, для HTML и CSS | |
| `ci18n_bidi_isolate(out, cap, text)` | Оборачивает одну строку в FSI и PDI | |
| `ci18n_bidi_mark(dir)` | LRM или RLM | |

## UTF-8

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_utf8_valid(text)` | Строго корректный ли это UTF-8 | |
| `ci18n_utf8_length(text)` | Символы, а не байты | |
| `ci18n_utf8_sequence_length(text)` | Байты в символе на этой позиции; никогда не 0 | |
| `ci18n_utf8_truncate(text, max)` | Режет до `max` байт, между символами | |

## Диагностика

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_last_error()` | Почему не сработал последний вызов этого потока | |
| `ci18n_error_string(err)` | То же текстом | |
| `ci18n_last_load_stats()` | Что последняя загрузка прочитала, выбросила и обрезала | |

## Каталоги

| Функция | Что делает | Выключает |
| --- | --- | --- |
| `ci18n_create()` | Новый пустой каталог | |
| `ci18n_destroy(catalog)` | Освобождает его; `NULL` допустим | |
| `ci18n_default()` | Каталог, с которым работают простые функции | |
| `ci18n_*_in(catalog, ...)` | Каждая функция выше, работающая с переводами, на этом каталоге | как выше |
| `ci18n_get_context()` | Каталог вызывающего потока, только с `CI18N_THREAD_LOCAL_CONTEXT` | |

## Ошибки

`ci18n_last_error()` возвращает один из этих кодов, а `ci18n_error_string()`
превращает его в текст.

| Код | Значение |
| --- | --- |
| `CI18N_OK` | Последний вызов прошёл успешно |
| `CI18N_ERR_NOT_INITIALIZED` | `ci18n_init()` не вызывался |
| `CI18N_ERR_INVALID_ARGUMENT` | `NULL` или иной непригодный аргумент |
| `CI18N_ERR_CODE_TOO_LONG` | Код языка длиннее `CI18N_MAX_CODE_LENGTH` |
| `CI18N_ERR_FILE_NOT_FOUND` | Файл не удалось открыть |
| `CI18N_ERR_OUT_OF_MEMORY` | Не удалось выделить память |
| `CI18N_ERR_TOO_MANY_LANGUAGES` | Достигнут `CI18N_MAX_LANGUAGES` |
| `CI18N_ERR_TOO_MANY_KEYS` | Достигнут `CI18N_MAX_KEYS_PER_LANGUAGE` |
| `CI18N_ERR_LANGUAGE_NOT_FOUND` | Такой язык не загружен |
| `CI18N_ERR_KEY_NOT_FOUND` | Такого ключа нет в просмотренных языках |
| `CI18N_ERR_PARSE` | Загрузка что-то выбросила или обрезала, или файл не того формата |
| `CI18N_ERR_TOO_MANY_FORMATTERS` | Достигнут `CI18N_MAX_FORMATTERS` |
| `CI18N_ERR_UNKNOWN_FORMATTER` | Перевод попросил форматтер, который никто не зарегистрировал |
| `CI18N_ERR_READ_ONLY` | Язык скомпилирован в программу и не может меняться |
