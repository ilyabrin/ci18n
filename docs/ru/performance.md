# Производительность

Замерено через `make bench` на Intel Core i5-12400F, gcc 13 с `-O2`, Linux,
русский каталог на 1 000 ключей с английским как запасным. У вас цифры будут
другими; как замеряется и как запустить, см. [bench/README.md](../../bench/README.md).

| Операция | Время |
| --- | ---: |
| `ci18n_get`, ключ найден | 24 нс |
| `ci18n_get`, найден в запасном языке | 38 нс |
| `ci18n_get`, ключа нет | 41 нс |
| `ci18n_format_plural` | 91 нс |
| `ci18n_format`, два плейсхолдера | 104 нс |
| `ci18n_format`, значение через форматтер | 170 нс |
| Загрузка 1 000 ключей | 0,17 мс |
| Загрузка 10 000 ключей | 1,5 мс |

Для сравнения, `gettext` из glibc на тех же ключах и той же машине тратит
133 нс на найденный ключ и 679 нс на отсутствующий (`make bench-gettext`).

С потоками чтение масштабируется по ядрам: один поток делает 27 миллионов
вызовов `ci18n_get` в секунду, а восемь потоков вместе 162 миллиона
(`make bench-threads`); см.
[Каталоги и потоки](catalogs-and-threads.md#shared-режим).

Размер кода и память описаны в разделе
[Встраиваемые системы и размер](embedded-and-size.md).
