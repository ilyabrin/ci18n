# Производительность

Замерено через `make bench` на Intel Core i5-12400F, gcc 13 с `-O2`, Linux,
русский каталог на 1 000 ключей с английским как запасным. У вас цифры будут
другими; как замеряется и как запустить, см. [bench/README.md](../../bench/README.md).

| Операция | Время |
| --- | ---: |
| `ci18n_get`, ключ найден | 28 нс |
| `ci18n_get`, найден в запасном языке | 44 нс |
| `ci18n_get`, ключа нет | 45 нс |
| `ci18n_format_plural` | 75 нс |
| `ci18n_format`, два плейсхолдера | 96 нс |
| `ci18n_format`, значение через форматтер | 159 нс |
| Загрузка 1 000 ключей | 0,18 мс |
| Загрузка 10 000 ключей | 1,7 мс |

Для сравнения, `gettext` из glibc на тех же ключах и той же машине тратит
140 нс на найденный ключ и 811 нс на отсутствующий (`make bench-gettext`).

С потоками чтение масштабируется по ядрам: один поток делает 26 миллионов
вызовов `ci18n_get` в секунду, а восемь потоков вместе 146 миллионов
(`make bench-threads`); см.
[Каталоги и потоки](catalogs-and-threads.md#shared-режим).

Размер кода и память описаны в разделе
[Встраиваемые системы и размер](embedded-and-size.md).
