## Подключение

В **одном** .c файле вашего проекта:

```c
#define CI18N_IMPLEMENTATION
#include "ci18n.h"
```

Во всех остальных файлах, которые её используют:

```c
#include "ci18n.h"
```

Это вся настройка. Если не хотите копировать заголовок, в разделе
[Установка](../../README.ru.md#установка) описаны CMake, pkg-config и
`make install`.

## Загрузка и выбор языка

```c
ci18n_init();
ci18n_load_language("en", "translations/en.txt");
ci18n_load_language("ru", "translations/ru.txt");
ci18n_set_current("ru");
ci18n_set_fallback("en");
```

Файл перевода это одна пара `key=value` на строку; см.
[Переводы](translations.md). Нет файловой системы? Загружайте из памяти через
`ci18n_load_from_buffer(code, text, length)`.

Запасной язык отвечает на каждый ключ, которого нет в текущем, так что
наполовину переведённый язык всё равно показывает что-то читаемое.

## Поиск

```c
printf("%s\n", ci18n_get("welcome_message"));
// or with fallback to key:
printf("%s\n", ci18n_get_or_key("missing_key"));
```

`ci18n_get()` возвращает `NULL` для ключа, которого нет ни у кого.
`ci18n_get_or_key()` вместо этого возвращает сам ключ, а в коде интерфейса
обычно нужно именно это: пропавший перевод покажется как `welcome_message`,
а не как падение.

Чтобы узнать, что загружено, передайте свой буфер. Возвращается общее число
языков, и оно может быть больше вашей ёмкости:

```c
const char *codes[CI18N_MAX_LANGUAGES];
size_t total = ci18n_get_languages(codes, CI18N_MAX_LANGUAGES);

for (size_t i = 0; i < total; i++) {
    printf("  - %s\n", codes[i]);
}
```

Передайте `NULL`, чтобы узнать только количество: `ci18n_get_languages(NULL, 0)`.

## Очистка

```c
ci18n_free();
```

## Когда что-то пошло не так

Каждый вызов, который может не сработать, записывает причину, а каждый
успешный её сбрасывает:

```c
if (!ci18n_load_language("en", path)) {
    fprintf(stderr, "%s: %s\n", path, ci18n_error_string(ci18n_last_error()));
}
```

Загрузчик возвращает `true`, если смог прочитать источник, и это ничего не
говорит о содержимом. Файл, где каждая строка испорчена, загрузится успешно,
с нулём записей. Спросите, что произошло на самом деле:

```c
ci18n_load_language("en", path);

const ci18n_load_stats_t *st = ci18n_last_load_stats();
if (st->lines_malformed) {
    fprintf(stderr, "%s: %u bad lines, first at line %u\n", path,
            (unsigned)st->lines_malformed,
            (unsigned)st->first_malformed_line);
}
```

Статистика также считает ключи, значения и строки, обрезанные до лимитов
`CI18N_MAX_*`. Если загрузка что-то выбросила или обрезала,
`ci18n_last_error()` остаётся равным `CI18N_ERR_PARSE`, так что если
подробности не нужны, хватит одной проверки.

Одно замечание про значения по умолчанию: `CI18N_MAX_LINE_LENGTH` и
`CI18N_MAX_VALUE_LENGTH` оба равны 4096, поэтому слишком длинное значение
сначала обрезается лимитом строки. Его хвост приходит следующей строкой без
разделителя и считается испорченным. Поднимите `CI18N_MAX_LINE_LENGTH` выше
`CI18N_MAX_VALUE_LENGTH`, если хотите, чтобы длинные значения обрабатывались
чисто. Лимиты перечислены в разделе
[Встраиваемые системы и размер](embedded-and-size.md#лимиты).

## Коды языков

Коды должны помещаться в `CI18N_MAX_CODE_LENGTH`, по умолчанию 32 байта
вместе с завершающим нулём. Более длинный код отклоняется с
`CI18N_ERR_CODE_TOO_LONG`, а не обрезается, потому что обрезка раньше
означала, что значение можно записать и никогда не прочитать обратно.

## Язык пользователя

```c
char locale[CI18N_MAX_CODE_LENGTH];
ci18n_detect_locale(locale, sizeof(locale));   /* "ru-RU" */

ci18n_set_current_best(NULL);                  /* use what the system says */
ci18n_set_current_best("ru-RU");               /* or a locale you choose */
```

`ci18n_detect_locale()` читает `LC_ALL`, `LC_MESSAGES` и `LANG`, а на Windows
спрашивает у системы локаль пользователя по умолчанию. Результат
нормализуется: `ru_RU.UTF-8` возвращается как `ru-RU`, а `C` и `POSIX` не
дают ничего, потому что не называют язык.

`ci18n_set_current_best()` отбрасывает подтеги, пока что-нибудь не совпадёт:
`ru-RU`, затем `ru`. Можно поставлять один простой файл `ru` и всё равно
учитывать пользователя, который просит русский в варианте для России. Если
ничего не совпало, текущий язык остаётся прежним.

Определите `CI18N_NO_PLATFORM_LOCALE`, чтобы не тянуть `windows.h` в сборку и
полагаться только на переменные окружения.

## Время жизни указателей

Каждый `const char *`, который возвращает API, указывает во внутреннюю память
библиотеки, поэтому он действителен только до следующего вызова, меняющего
этот язык:

```c
const char *greeting = ci18n_get("greeting");
ci18n_load_language("en", "extra.txt");   /* may realloc */
puts(greeting);                           /* dangling */
```

`ci18n_set()`, `ci18n_remove()` и загрузчики могут перевыделить массив
записей. `ci18n_clear()`, `ci18n_free()` и `ci18n_set_current()` делают
указатели недействительными сразу. Читайте перевод прямо перед
использованием, это дёшево, или копируйте его через `ci18n_get_copy()`, если
нужно его сохранить. С потоками копируйте всегда; см.
[Каталоги и потоки](catalogs-and-threads.md#shared-режим). Исключение это
строка из [скомпилированного языка](compiled-catalogs.md): она живёт столько
же, сколько программа.

## Проверка версии

```c
#if CI18N_VERSION < CI18N_VERSION_NUMBER(2, 6, 0)
#error "ci18n 2.6.0 or newer is required"
#endif

printf("ci18n %s\n", CI18N_VERSION_STRING);
```
